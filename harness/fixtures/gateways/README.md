`portkey/` holds three real responses of the open-source Portkey gateway 1.15.2 (`portkeyai/gateway:1.15.2`, digest `sha256:97f094d9c8a764cbfaa2a7138c0017b247ca923bb06db1b4c13b7f8a33b5200d`), captured on 2026-09-23 against a local echo upstream that answers with the requested model: `plain.json` (provider headers only; the stock image reports `x-portkey-cache-status: DISABLED`), `override-params.json` (a config whose `override_params` changes the model) and `input-mutator.json` (a config whose `default.addPrefix` mutator reports `transformed: true`). Each file keeps the requested model, the status, the `x-portkey-*` and `content-type` headers, and the body.

`source-derived.json` holds markers the stock images cannot produce locally, written from the pinned vendor source cited in each entry's `source` field, not captured: Portkey's cache status header (caching is compiled out of the stock image) and Bifrost's `extra_fields` markers.
