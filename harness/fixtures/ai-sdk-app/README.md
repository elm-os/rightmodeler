# AI SDK fixture app

A standalone, inert AI SDK app whose captured telemetry is committed under `harness/fixtures/traces/ai-sdk-*.jsonl`. It pins `ai` 7.0.110, `@ai-sdk/otel` 1.0.110, `ai-v6` (npm `ai@6.0.288`), `@opentelemetry/api` 1.9.1, `@opentelemetry/context-async-hooks`, `@opentelemetry/resources` and `@opentelemetry/sdk-trace-base` 2.11.0, `@opentelemetry/otlp-transformer` 0.222.0 and `zod` 4.6.5, exactly, through `package.json` and its own `package-lock.json` (it is outside the pnpm workspace). The six call sites in `src/` call a deterministic mock model from `src/provider.mjs`; `generate.mjs` runs the call plan and writes OTLP JSON lines to stdout. Never create `node_modules` inside this directory: regenerate from a scratch copy with `CAP=$(cd "$(mktemp -d "${TMPDIR:-/tmp}/rightmodeler-ai-sdk-XXXXXX")" && pwd -P)`, `cp -R harness/fixtures/ai-sdk-app "$CAP/app"`, `(cd "$CAP/app" && npm ci --ignore-scripts)`, then `(cd "$CAP/app" && node generate.mjs v7-legacy) > ai-sdk-v7-legacy.jsonl`, `(cd "$CAP/app" && node generate.mjs v7-legacy --split --traces 8) > ai-sdk-v7-legacy-split.jsonl`, `(cd "$CAP/app" && node generate.mjs v7-genai) > ai-sdk-v7-genai.jsonl` and `(cd "$CAP/app" && node generate.mjs v6 --traces 24) > ai-sdk-v6.jsonl`, and copy the four files into `harness/fixtures/traces/`.
